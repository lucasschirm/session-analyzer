# tests/

Test suites for the site package.

## Directories

- **unit/** — Vitest unit tests for source code and utilities. See `unit/AGENTS.md`.
- **unit/helpers/** — Unit tests for shared E2E helpers. See `unit/helpers/AGENTS.md`.
- **e2e/** — Playwright end-to-end tests and fixture files.
- **e2e/helpers/** — Shared Playwright helpers and their own E2E regression specs. See `e2e/helpers/AGENTS.md`.
